# 进度记录：BoardPet

## M1 宠物核心（P4）
- 完成内容：Electron 骨架与 IPC 通道；参数化 SVG 球员（12 位球星预设 + 自定义：肤色/发型/胡须/球衣主副色/号码/名字）；拖拽移动（3px 阈值区分点击）、滚轮缩放、走动引擎（走停随机节奏+边界转向）、庆祝/轻反应/沮丧动画、托盘菜单、设置持久化（settings.json 版本化）。
- 与计划偏差：形象方案由「AI 生成位图」改为「参数化 SVG」——调研阶段发现的素材一致性问题，已在对齐单默认假设范围内（写进了调研报告风险表）。
- 修复：①ESPN 无数据时无碍；②经典脚本函数名泄漏导致渲染白屏（改 IIFE）；③大胡子形状改为下巴月牙。

## M2 数据层（P4）
- 完成内容：ESPN 三接口封装（scoreboard/summary/teams，UA+超时+重试）；解析函数纯化（parseScoreboard/parseSummary/parseTeams）；内存缓存（赛程 45s、详情 20s、终场 1h）；关注事件检测器（开赛/下半场/反超/追平/8+高潮/赛果胜败，首轮静默防轰炸）；系统通知（点击直达详情窗）；45s 轮询器。
- 与计划偏差：boxscore 列映射从 labels 改为优先用 ESPN 的 `keys` 机器名——实测 labels 为 `FG/3PT/FT` 与预期 `FGM-A` 不符，keys 更稳定，labels 保留兜底。
- 测试：单测 11 个全过（解析归一化/容错、关注判定、7 类事件场景）。

## M3 面板（P4）
- 完成内容：赛程面板（当日+前后翻日、胜负高亮、星标/屏蔽按钮、关注标签）；比赛详情窗（比分头、双方 tab、11 列 box score、20s 自动刷新、可多开）；设置面板（球员卡预览选择、自定义名字/号码、球队配色下拉+取色器、30 队关注多选、大小滑杆、行为开关 5 项）。
- 修复：①`resizePet` 百分比上限误用于像素值（160% 被钳到 250px）；②Windows 125% DPI 下透明无边框窗口反复 setPosition 导致**尺寸持续漂移**（实测 200px 窗口 10 秒内涨到 615px）——走动改用带固定宽高的 setBounds 后稳定；③镜像朝向时球衣文字反写——加 CSS 反镜像。
- 验证：冒烟脚本截图 6 张（宠物/赛程/详情/设置/切库里/160%），端到端交互确认「设置切球员→宠物即时更新」「滑杆→窗口正确缩放」。
- 下一步：M4 联动与打包（提醒/庆祝全链路已实现待联调、托盘图标、electron 打包绿色版）。

## M4 联动与交付（P4）
