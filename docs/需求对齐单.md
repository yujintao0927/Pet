# 需求对齐单：BoardPet 篮球桌面宠物　日期 2026-10-10（对齐完成待终确认）

## 当前理解
在 Windows 上用 Electron 做一个篮球主题桌面宠物「BoardPet」：默认形象为 Q 版勒布朗·詹姆斯（76 人红蓝配色），预置 10~20 位热门球星 Q 版形象，其他球员用通用身体 + 自选球队配色/球衣号码/名字；宠物常驻桌面、可拖拽、可滚轮+设置调大小，有活泼行为（待机运球动画、桌面底部走动）。

点击宠物弹出 NBA 赛程面板；点开比赛弹独立窗口看实时比分（节次/比分/时间）与双方球员 box score，可同时开多场。关注机制为「我的球队（默认 76 人）+ 单场星标加减」：仅关注的比赛触发提醒与庆祝；比赛开始与下半场开始时发 Windows 系统通知（点击直达该场详情窗）+ 宠物动作；关注的球队出现关键时刻（反超/追平/得分高潮/胜负已分）时宠物大庆祝，平时得分仅轻反应。数据走免费公开 NBA 接口，30~60 秒准实时刷新。

主流程：启动 → 宠物出现在桌面 → 点击弹赛程面板 → 点开比赛看实时数据；关注球队开赛/下半场开始收到提醒；关键时刻宠物庆祝。右键/设置：换形象、配色、调大小、管理关注球队与单场星标、开机自启等开关。

## 范围外（明确不做）
- 不做比赛视频/直播流播放，不做录像回放
- 不做高阶数据分析（热图、进阶统计、AI 预测）
- 不做多语言界面（仅中文）、不做 macOS/Linux（仅 Windows 10/11 x64）
- 不接付费数据源，不做账号/登录/云同步
- 不做宠物养成游戏化系统（喂食、升级等）
- 一期不支持用户上传任意图片作为形象

## 默认假设（未确认，按此执行，随时可改）
- 个人自用；应用名沿用 BoardPet
- 数据使用免费公开 NBA 接口（非官方公开端点），约 30~60 秒刷新；非直播级实时
- 球员数据为基础 box score：得分、篮板、助攻、命中率、正负值等
- Q 版形象素材用 AI 生成、统一风格，首个做詹姆斯
- 宠物窗口：置顶、不点击穿透、可拖拽，均提供设置开关；走动范围为屏幕底部「地面」，不上全屏乱跑；仅主显示器
- 调整大小：鼠标滚轮缩放 + 设置面板数值
- 赛程面板默认显示当日比赛，可切换日期查看近几日
- 无网络/接口失败时显示「数据不可用」，宠物本体行为不受影响
- 交付形态：免安装绿色版，提供开机自启开关
