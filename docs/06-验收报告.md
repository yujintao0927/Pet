## 非功能指标实测（打包产物，30s 窗口）
| 指标 | 目标 | 实测 | 判定 |
|---|---|---|---|
| 空闲 CPU | <1%（单核） | 0.99%（歇息态；走动时段瞬时升高属产品行为，PRD 已注明） | 达标 |
| 内存（主+渲染合计） | <200MB | **318.3MB**（主 89.8 / 渲染 112.6 / GPU 67.9 / 工具 47.9） | **不达标，申请豁免** |
| 面板打开时延 | ≤500ms | 本地页面加载 <300ms（人工观察） | 达标 |
| 安全基线 | contextIsolation 等 | 全部 preload 均开启 contextIsolation、无 nodeIntegration，CSP 已设 | 达标 |

**内存豁免理由**：318MB 为 Electron 39 空载基线的正常水平（单透明动画窗口 + 4 进程），与应用逻辑无关（宠物体量仅一个 SVG + 轮询缓存）；用户在第 1 轮选型时已明确知晓并接受「Electron 内存占用偏高」的代价。后续若需压至 200MB 内，需更换运行时（Tauri/原生），属重新立项决策。

## 发布记录（首次发布）
- **产物**：`release/BoardPet-win32-x64/`（327MB，含 `BoardPet-v0.1-win32-x64.zip` 压缩包）；免安装：整个文件夹拷贝到任意位置，双击 `BoardPet.exe` 即用。
- **打包步骤**（可复现）：
  1. `npm install`（国内网络需 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`）
  2. `node scripts/gen-icon.js`（生成 icon.ico/tray.png/icon.png）
  3. `MSYS_NO_PATHCONV=1 npx electron-packager . BoardPet --platform=win32 --arch=x64 --icon=assets/icon.ico --out=release --overwrite --prune=true --ignore="^/(release|docs|tests|scripts|smoke|\.git)"`
     > ⚠️ 后补说明（2026-10-10 迭代2 期间发现）：在 Git Bash 中执行时必须带 `MSYS_NO_PATHCONV=1`，否则 shell 会把 `^/(release...)` 改写成 `^D:/Git/(release...)`，`--ignore` 静默失效，docs/tests/node_modules 会被打进 `app.asar`（实测曾膨胀到 342MB）。校验方法：产物 `resources/app.asar` 应约 160KB。
- **配置项清单**：全部配置存于 `%APPDATA%\BoardPet\settings.json`（版本化 v1），首启自动生成默认值（詹姆斯/76 人/关注 PHI/走动+置顶+通知+庆祝开启）。删除该文件即恢复出厂。
- **数据初始化**：无需初始化；球队列表来自内置 presets（30 队配色）；球员预设 12 位。
- **升级方式**：覆盖 release 文件夹；settings.json 在用户目录不受影响（结构带 version 字段，向后兼容合并）。
- **卸载**：删除程序文件夹 + `%APPDATA%\BoardPet`。
- **已知问题**：①F13/F14 待真实赛事补验；②内存超目标（豁免）；③打包态日志中出现 Gpu Cache Creation 警告（便携目录常见，不影响功能）。
