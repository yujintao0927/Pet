# 测试计划：BoardPet v0.1　日期 2026-10-10

## 结论
单元测试锁数据解析与事件检测（11 用例）；E2E 通过「冒烟脚本自动截图 + 断言日志 + 打包产物重跑」验证 8 条用户核心路径。P0 用例 100% 通过方可发布；F13/F14 真实赛事触发因当日无进行中比赛列为受限项（由单测覆盖 + 上线后补验）。

## 1. 范围与环境
- 测什么：数据解析、关注事件检测（单元）；宠物交互、三面板数据流、个性化、容错、打包产物（E2E）。
- 不测什么：真实直播比赛中的通知弹出时机（无直播场次）、系统重启后的自启注册效果、多显示器。
- 环境：Windows 10/11 x64（125% DPI），Node 22，Electron 39.8.10；数据源 ESPN 线上真实接口。
- 数据准备：单测用 tests/fixtures 下按真实响应裁剪的固件；E2E 用当日真实赛程（HOU@DAL、MEM@CHI，均已结束）。
