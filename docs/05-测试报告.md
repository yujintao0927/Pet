## 2. 缺陷列表
| 编号 | 描述 | 严重级别 | 状态 |
|---|---|---|---|
| B01 | 透明无边框窗在 Windows 125% DPI 下反复 setPosition 导致窗口尺寸持续漂移（200px 实测 10s 涨到 615px），走动后画布错位 | P0 | 已修复（走动改用带固定宽高的 setBounds），回归通过 |
| B02 | boxscore 列映射按 ESPN labels 匹配失败（实际为 FG/3PT/FT），投篮/三分/罚球列全空 | P0 | 已修复（优先用稳定 keys，labels 兜底），单测 U03 锁定 |
| B03 | resizePet 把 60~250% 的百分比上限误用作像素钳制，160% 被截为 250px | P1 | 已修复，E2E E03 验证 |
| B04 | 镜像朝向时球衣号码/名字反写不可读 | P1 | 已修复（CSS 反镜像），E2E E04 验证 |
| B05 | 经典脚本函数名泄漏导致宠物渲染白屏 | P1 | 已修复（IIFE 包裹），E01 回归 |
| B06 | 启动位置越界不自愈：保存的窗口坐标若落到屏幕外（曾因冒烟脚本反复缩放把 y 累积推到 -672），宠物永久隐身，托盘「显示宠物」也无效 | P0 | 已修复：启动时校验并自愈（越界即回默认右下角并写回配置）、拖拽/缩放全程钳制在屏内、`showPet` 兜底校验；新增冒烟断言「缩放后窗口必须完整在工作区内」；冒烟测试改用隔离配置目录，绝不再污染用户真实设置 |
