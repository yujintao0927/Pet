# PRD：BoardPet 篮球桌面宠物　版本 v0.1　日期 2026-10-10

## 结论
本期交付 v0.1 完整功能版：Electron 桌面宠物（默认 Q 版詹姆斯、76 人配色），支持形象个性化、调大小、走动/待机动画；NBA 数据基于 ESPN 免费公开接口，提供赛程面板、比赛详情窗（实时比分 + 双方球员 box score）、关注机制、开赛/下半场系统通知提醒与关键时刻庆祝。范围依据 docs/需求对齐单.md（对齐已完成）。

## 1. 功能需求
| 编号 | 模块 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| F01 | 宠物本体 | 应用启动后宠物窗口出现在主屏右下角，透明背景、无边框、置顶、不进任务栏 | P0 | Given 启动应用 When 桌面渲染完成 Then 宠物显示在主屏右下角且遮挡测试通过（置顶）、任务栏无该窗口 |
| F02 | 宠物本体 | 按住宠物可拖拽到屏幕任意位置，位置持久化，重启恢复 | P0 | Given 宠物在 A 点 When 拖拽到 B 点并重启应用 Then 宠物出现在 B 点 |
| F03 | 宠物本体 | 鼠标滚轮悬停缩放（60%~250%），设置面板提供大小滑杆，大小持久化 | P0 | Given 宠物 100% When 滚轮向上 Then 变大且比例不失真；重启后保持 |
| F04 | 宠物本体 | 待机动画：原地运球 + 呼吸起伏，循环播放 | P0 | Given 宠物空闲 When 观察 10s Then 运球手臂与篮球弹跳循环且不卡顿 |
| F05 | 宠物本体 | 桌面走动：沿屏幕工作区底边随机左右走动、转向，可被拖拽打断，可开关 | P1 | Given 走动开启 When 空闲 1 分钟 Then 宠物水平位移变化且不超过屏幕底边范围；拖拽时立即停下 |
| F06 | 形象个性化 | 预置热门球星 Q 版形象（含詹姆斯），选择后立即生效 | P0 | Given 设置面板 When 选择「库里」Then 宠物外观变为库里预设（肤色/发型/胡须/球衣配色/号码） |
| F07 | 形象个性化 | 通用球员自定义：输入名字、号码，选择任意 NBA 球队作为配色，或单独换球衣主色/副色 | P0 | Given 选择自定义 When 输入名字+号码+选球队 Then 宠物球衣变色、胸前显示号码与名字 |
| F08 | 形象个性化 | 默认形象为勒布朗·詹姆斯、76 人配色，首次启动即生效 | P0 | Given 全新安装 When 首次启动 Then 宠物为詹姆斯形象 + 76 人红蓝球衣 |
| F09 | 赛程面板 | 单击宠物弹出赛程面板：当日比赛列表（队徽/对阵/比分或开赛时间/状态），支持前一日/后一日切换 | P0 | Given 有比赛的日期 When 打开面板 Then 列出全部比赛；无比赛时显示空态文案 |
| F10 | 比赛详情 | 点击面板中任意比赛打开独立详情窗：大比分、节次、比赛时钟、状态；双方球员 box score 表（姓名/时间/得分/篮板/助攻/投篮/正负值），可同时多开 | P0 | Given 进行中的比赛 When 打开详情 Then 比分与节次正确、双方球员数据行完整；两场比赛窗口可并存 |
| F11 | 数据刷新 | 进行中比赛自动刷新：面板 45s、详情窗 20s；比赛结束后停止刷新 | P0 | Given 详情窗打开 When 20s 后 Then 比分/数据更新（与 ESPN 网页对照误差 ≤1 个回合） |
| F12 | 关注机制 | 设置中维护「我的球队」多选（默认 76 人）；赛程面板任意比赛可星标关注/取消 | P0 | Given 已关注球队 When 该队当日有比赛 Then 面板中该场带星标；手动星标任意场次同样生效 |
| F13 | 提醒 | 关注的比赛：开赛、下半场（第 3 节）开始时发 Windows 系统通知（点击打开对应详情窗）+ 宠物做示意动作 | P0 | Given 关注比赛未开赛 When 检测到开赛 Then 系统通知出现且点击可打开详情窗；下半场开始同样触发 |
| F14 | 庆祝 | 关注的比赛出现关键时刻（比分反超/追平、单次刷新间隔内得分 ≥8、比赛胜负已分）时宠物播放庆祝动画；平时得分仅轻微反应 | P0 | Given 关注比赛 When 主队反超 Then 宠物跳跃欢呼动画；普通得分仅小幅动作 |
| F15 | 设置 | 设置面板：形象选择与自定义、我的球队、大小、行为开关（走动/置顶）、提醒开关、开机自启 | P0 | Given 任意开关变更 When 关闭面板再打开 Then 设置保持且立即生效 |
| F16 | 容错 | 断网或接口异常时面板/详情显示「数据暂不可用」与重试按钮，宠物本体不受影响 | P0 | Given 断网 When 打开面板 Then 显示空态与重试；宠物动画正常 |
| F17 | 托盘 | 系统托盘图标：显示/隐藏宠物、打开设置、退出 | P1 | Given 点击托盘菜单 When 选「隐藏宠物」Then 宠物窗口隐藏，再选显示则恢复 |
| F18 | 交付 | 免安装绿色版打包（portable），提供开机自启开关 | P1 | Given 执行打包 When 运行产物 Then 无需安装即可启动全部功能 |

## 2. 非功能需求
| 类别 | 要求 | 指标 |
|---|---|---|
| 性能 | 空闲资源占用低 | 空闲 CPU <1%（不含动画渲染瞬时值），主进程+渲染合计内存 <200MB |
| 性能 | 界面响应 | 面板/详情窗打开 ≤500ms；动画 60fps 不卡顿 |
| 安全 | Electron 安全基线 | contextIsolation=true、nodeIntegration=false、preload 桥接；仅访问 ESPN 只读接口 |
| 兼容 | Windows 10/11 x64，中文界面 | Win10 1909+ 正常运行 |
| 可维护性 | 数据解析集中、单元测试 | ESPN 响应解析器有单测覆盖；配置 JSON 结构有版本号 |
| 隐私 | 无遥测 | 不上报任何数据 |

## 3. 依赖与约束
- 数据源：ESPN 免费公开接口（site.api.espn.com，只读、免密钥）；NBA 官方接口在本网络不可用（已实测，见调研报告）。
- 运行环境：Node 22（开发）、Electron（运行时）、Windows 10/11 x64。
- 网络可用性影响实时数据功能；宠物本体离线可用。

## 4. 开放问题
- 无（原开放问题已全部通过对齐与默认假设关闭；数据源具体选 ESPN 属于「免费公开接口」默认假设范围内的落实）。
